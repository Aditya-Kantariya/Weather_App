# ⛅ Weather Forecast Web Application

A modern and responsive **Weather Forecast Web App** built using **HTML, CSS, and JavaScript** that provides real-time weather updates, 5-day forecasts, air condition metrics, and favorite city management using the WeatherAPI service.

This project demonstrates strong frontend development skills, API integration, asynchronous JavaScript handling, responsive UI design, and local storage management.

---

## 🚀 Features

- 🌍 Search weather by city name
- 📅 5-Day weather forecast
- 🌡️ Real-time temperature and weather conditions
- 💨 Air condition metrics:
  - Feels like temperature
  - Wind speed
  - UV index
  - Visibility
  - Pressure
  - Chance of rain
- ❤️ Add/Remove favorite cities
- 💾 Favorites saved using LocalStorage
- 🎨 Modern glassmorphism UI design
- 📱 Fully responsive layout for desktop and mobile
- ⚡ Async/Await based API integration
- 🔄 Loading spinner and error handling
- 🌤️ Dynamic weather icons using Weather Icons library
